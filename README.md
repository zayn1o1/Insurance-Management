# Automobile Insurance Information System

Console-based C++ information system for an automobile insurance company.

## Features

- Register customers, vehicles, workshops, and staff.
- Create insurance policies.
- File claims for insured vehicles.
- Assign surveyors and record inspection reports.
- Manager approval/rejection of claims based on inspections.
- Record repairs only at registered workshops.
- Generate operational reports:
  - New customers in a month.
  - Pending claims.
  - Inspection reports.
  - Previous claims by customer.

## Build And Run

```bash
make
make run
```

Data is stored in plain text files under `data/`. No DBMS is used.
